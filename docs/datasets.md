# L&I contractor datasets on data.wa.gov

Checked 2026-10-20 ~20:40 UTC from a cloud session (data.wa.gov reachable). All three are Socrata datasets keyed on `contractorlicensenumber` (also `ubi`). API: `https://data.wa.gov/resource/<id>.json` with SoQL (`$select`, `$where`, `$group`, `$order`, `$limit`, default limit 1000).

## Key findings for the workflow

- **Insurance (ciwg-agsx) holds multiple policies per license.** 77,223 rows for 71,214 distinct licenses; 5,531 licenses have more than one row (max 9). Example `STARTFL790QE` has 9 rows: GL, WC, umbrella, auto, pollution etc., all effective 2026-01-01, plus one exact duplicate GL row (same policy no., different `lastupdatedate`). Most licenses (e.g. `04CONCL862CR`, `100PLRL754Q5`) have one row. Dedupe on (license, `insurancepolicyno`) keeping latest `lastupdatedate`; decide whether "insurance expiring" means the earliest-expiring policy or the GL policy.
- **Insurance only contains current policies.** min(`expirationdate`) = 2026-10-21 (tomorrow), so expired policies drop out of the snapshot. Only license statuses A/R/B appear. So "expiring in next N days" = `expirationdate between today and today+N`. Right now: 2,152 rows expire 2026-10-20..2026-11-03 with `canceldate` null.
- **`canceldate`**: 2,365 rows non-null; 42 are in the future (scheduled cancellations). Treat a non-null `canceldate` as its own "cancelling" category in reports.
- **Data quirks**: 74 rows have `expirationdate` after 2030 (max 8027-08-01, a typo); `insuranceamt` is a decimal string ("1000000.0000"); `phonenumber` and `ubi` are typed number but come back as strings.
- **"Plumbing companies" is two things.** Plumbing contractor license type `contractorlicensetypecode = 'PC'` (3,106 total, 2,198 active) AND construction contractors with `specialtycode1 = 'AD'` (PLUMBING, 1,230). Specialty codes are reused across license types (`01` = GENERAL for CC/EC, JOURNEY LEVEL for PC; `02` RESIDENTIAL for EC and PC), so always filter on type + code together, never on description alone. 464 EC rows have code `09` with no description.
- **Electrical (EC) and elevator (LC) contractors are mostly absent from insurance**: only 272 EC licenses and 0 LC have insurance rows (5,565 EC active). Insurance asks for those trades will be near-empty; the report should say so.
- **Bond (bzff-4fmt)**: 177,141 rows / 82,983 licenses, keeps bond history (old + current bonds per license). `bondexpirationdate` is **text**: "Until Canceled" or "MM/DD/YYYY", so it can't be range-filtered in SoQL; parse client-side.
- General (m8qx-ubtq) is one row per license (161,704 rows = 161,704 distinct), all statuses incl. expired.
- All three refreshed today (rowsUpdatedAt 2026-10-20 19:33-19:42 UTC).

## Example query: plumbing insurance expiring in 14 days

```
GET https://data.wa.gov/resource/ciwg-agsx.json
  ?$where=expirationdate between '2026-10-20' and '2026-11-03' AND canceldate IS NULL AND contractorlicensetypecode='PC'
```
then for CC plumbers, fetch license numbers from m8qx-ubtq with `specialtycode1='AD' AND contractorlicensetypecode='CC' AND statuscode='A'` and filter insurance by `contractorlicensenumber in (...)` (batch the IN list).
